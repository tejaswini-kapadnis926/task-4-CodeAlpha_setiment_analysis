#  CodeAlpha Sentiment Analysis Project

## 🚀 Project Overview

This project focuses on analyzing customer sentiment from e-commerce product data using Natural Language Processing (NLP) techniques.
The main objective is to classify customer sentiment as Positive, Negative, or Neutral and understand customer opinions through data analysis and visualization.
---

# 🛠️ Technologies Used
* Python
* Pandas
* TextBlob
* Matplotlib
* Seaborn
* Jupyter Notebook

---

# 📊 Sentiment Analysis Performed
✔ Text Data Processing
✔ Sentiment Classification
✔ Positive/Negative/Neutral Analysis
✔ Data Visualization
✔ Customer Opinion Analysis

---

# 📈 Visualizations Created

* Sentiment Distribution Countplot
* Rating Analysis
* Customer Opinion Visualization
---

# 🎯 Key Insights
* Most customer sentiments were positive.
* Negative reviews were comparatively fewer.
* Sentiment analysis helps understand customer satisfaction and product performance.
